# Liquid Glass — Obsidian カスタムテーマ

Obsidian デフォルトテーマの上に「ガラスの面」だけを上書きするカスタムテーマです。
タイトルバー・リボン・サイドバー・タブ・本文・ステータスバー・ダイアログを、
ぼかしの効いた半透明の角丸パネルとして塗り直します。それ以外（フォントサイズ、
行間、寸法、ウィンドウ操作、リサイズ機能など）は既定の挙動をそのまま残します。

---

## インストール

1. ボルトの `.obsidian/themes/Liquid Glass/` フォルダを作る
2. `theme.css` / `manifest.json` / `versions.json` をそこにコピーする
3. Obsidian → 設定 → 外観 → テーマ で「Liquid Glass」を選ぶ

コピーしたあとは Obsidian で **Ctrl+R**（再読み込み）してください。
`theme.css` の先頭に `/* rev ... */` という行があります。ここが最新の rev と一致していれば、
コピーは最新です（古いと、古い見た目のままになります）。

### 注意

- 設定 → 外観 の **「半透明のウィンドウ」はオフ推奨**。オンにすると OS のウィンドウ透過と
  このテーマの壁紙（`body` の背景）が競合します。
- フォント（`--font-*` / `--line-height-*`）と寸法（`--header-height` / `--ribbon-width` /
  `--divider-width` など）は触っていません。
- ウィンドウの操作ボタン、ペインのリサイズは既定どおり動きます。
- ウィンドウの移動は次の 2 か所でできます。① 既定どおりタブバーの**空き部分**（タブと
  タブの間や右側の余白）、② パネルの外側の**上端のすき間**（メインのノートブロックの
  上の背景）。タブを多く開いても ② があるので移動しやすいです。すき間を広げたい場合は
  Style Settings の「すき間（gap）」を大きくしてください（その分ドラッグ領域も広がります）。

---

## ファイル

| ファイル | 役割 |
|---|---|
| `theme.css` | テーマ本体。デフォルトテーマに重ねる上書きだけを書いた 1 枚もの |
| `manifest.json` | テーマ名・バージョン・最低対応バージョン |
| `versions.json` | バージョンと最低対応 Obsidian の対応表 |

## カスタマイズ

### Style Settings プラグイン経由（おすすめ）

[Style Settings](https://github.com/mgmeyers/obsidian-style-settings) を入れておくと、
設定 → Style Settings → Liquid Glass から次を調整できます。

| 項目 | 対応する変数 | 既定 |
|---|---|---|
| 背景のぼかし | `--lg-blur` | `24px` |
| 背景の彩度 | `--lg-saturate` | `180%` |
| パネル同士のすき間 | `--lg-gap` | `10px` |
| サイドバー等の透過度 | `--lg-chrome-alpha` | `0.44` |
| 本文・ダイアログの透過度 | `--lg-surface-alpha` | `0.62` |
| 角丸の大きさ | `--lg-radius-scale` | `1` |
| 角のカーブ | `--corner-shape` | `squircle` |
| 壁紙をオフにする | クラス `lg-no-wallpaper` | オフ |
| 壁紙に画像を使う | `--lg-wallpaper-photo` | `none` |

### CSS 変数を直接いじる / CSS スニペットで上書きする

数値はすべて `body` の CSS 変数に集約してあります。スニペットなどで `body { … }` を
書けば上書きできます。

```css
/* 例: ぼかしを弱めて省電力にする */
body { --lg-blur: 12px; }

/* 例: 壁紙を自作のグラデーションにする（丸ごと差し替え） */
body {
  --lg-wallpaper: linear-gradient(160deg, #101528 0%, #05060c 100%);
}

/* 例: 壁紙に写真を敷く（--lg-wallpaper の上に重なります） */
body {
  --lg-wallpaper-photo: url("https://example.com/bg.jpg");
}

/* 例: コールアウトの色の濃さ／ガラスを調整する */
body {
  --lg-callout-tint: 0.22;                        /* 種類の色を濃く（0 で無色） */
  --lg-callout: rgba(255, 255, 255, 0.12);        /* ガラスを明るく */
  --lg-callout-backdrop: blur(20px) saturate(180%);
}

/* 例: 引用の面の濃さ（背表紙の色は --color-accent に従います） */
body { --lg-quote: rgba(255, 255, 255, 0.12); }
```

#### 壁紙まわり

- 壁紙は `body` の `background-image: var(--lg-wallpaper)` として描かれます（固定）。
- `--lg-wallpaper-photo` に `url(...)` を入れると、`body::before` の画像レイヤーが
  メッシュの上に重なります。写真を使うときは「壁紙をオフにする」と併用すると
  すっきりします（下地のグラデーションを消して写真だけにできます）。
- 壁紙を完全に消したいときは `lg-no-wallpaper` クラス（Style Settings のトグル）か、
  `body { --lg-wallpaper: none }` を使ってください。

#### 色（tint）

ダーク／ライトで非対称にならないよう、tint の色そのものは Style Settings には
出していません。変えたい場合は `--lg-chrome-color` / `--lg-surface-color`（ベース色）と
`--lg-chrome-alpha` / `--lg-surface-alpha`（不透明度）を上書きしてください。

#### 半透明ウィンドウ（Acrylic / Mica）

ポップアウトのように「透かしたいウィンドウ」で `body` に `is-translucent` が付くと、
テーマは不透明な下地を持たない `--lg-wallpaper-ghost`（メッシュだけの壁紙）に自動で
差し替えます。下地が消えるので OS の素材がそのまま透け、テーマの色味だけが上に乗ります。
「壁紙をオフにする」を併用している場合は、下地も描かず完全に透明になります。

**メインウィンドウは既定で `is-translucent` が付かないため、通常の不透明な壁紙のまま**
です。テーマの既定の見た目は変わりません（メインを透かしたくない場合は、この状態が
そのまま使えます）。

- 判定は `is-translucent` だけなので、どのウィンドウでも同じルールで効きます。
- OS 側がすでにぼかしているため、テーマのぼかしと二重になります。気になる場合は
  Style Settings の「背景のぼかし」を `0` にしてください。
- 色味は `--lg-wallpaper-ghost` を上書きして調整できます。

##### ポップアウトだけを透かす（補助プラグイン）

ポップアウト（別ウィンドウ）は、Obsidian がウィンドウを生成する流れの中で背景素材を
上書きしてしまうため、既存のプラグイン（メインウィンドウ1枚にしか効かない作り）では
透けません。素材を当てるのは CSS の仕事ではないので、テーマ側だけでは手が出せない
部分です。そこで `plugin/liquid-glass-backdrop/`（ローカル補助プラグイン）を同梱して
います。**メインを透かす必要はないので、Translucent BG / Pseudo Mica は無効化して
構いません。**

1. ボルトの `.obsidian/plugins/liquid-glass-backdrop/` を作る
2. `plugin/liquid-glass-backdrop/main.js` と `manifest.json` をコピーする
3. Obsidian を再起動 → 設定 → コミュニティプラグイン で有効化

- **メインウィンドウには触りません**（ポップアウト専門）。メインはテーマの既定の
  不透明な見た目のままです。
- 素材は `main.js` の `MATERIAL` で変えられます（`acrylic` / `mica` / `tabbed`）。
- メインもまとめてこのプラグインに任せたいときは `INCLUDE_MAIN_WINDOW` を `true` に
  してください（その場合は他プラグインをオフに）。
- プラグインを切ると、ポップアウトは元の不透明な見た目に戻ります（`is-translucent` も
  外します）。

## 設計メモ

- **上書き専用**。Obsidian のデフォルトテーマ（`app.css`）は必ず先に読み込まれるので、
  ここでは差分だけを書いています。
- できるだけ Obsidian 自身の CSS 変数を置き換える形にし、`!important` は
  「塗りを奪う」箇所（パネル背景・タブのアクティブなリム・`.cm-*` など）に限定しています。
- 角丸は Obsidian の `--radius-*` を置き換えることで、アプリ全体に一括で効かせています。
- `corner-shape: squircle` は未対応エンジンでは宣言ごと無視され、通常の円弧になります。
- モバイル（`body.is-mobile`）では `--lg-gap: 0` にして、全画面の角丸・`overflow: hidden` を
  当てないようにしています（画面端の UI を切らないため）。
- **左サイドバーの開閉ボタン**：既定ではリボン（左端のアイコン列＝設定などがある
  箱）の左上に浮いて見え、パネルを浮かせるこのテーマではレールの外に出てしまい
  ます。そこでリボンに `position: relative` を与えてボタンの基準をリボン自身にし、
  レールの上端をタブバー行の高さまで伸ばして、ボタンをレールの先頭行に収めて
  います（アイコン列の位置は既定と同じに保っています）。
  なおリボン本体の class は Obsidian のバージョンにより `mod-left`（旧）と
  `mod-primary`（新）があるため、セレクタは両方を並べて書いています。片方だけだと
  ルールが当たらず、ボタンがリボンの外（ウィンドウ左上）に浮いたままになります。
- **ウィンドウ操作ボタン（最小化／最大化／閉じる）**：Windows / Linux の隠しフレーム表示では
  Obsidian 自身が `.titlebar-button` を描画します（OS のオーバーレイではないので CSS が効きます）。
  既定は高さ 39px の横長ボタンなので、14px の丸に置き換えて、パネルのさらに上
  （上端に確保した帯＝`--lg-btn-strip`、既定 14px）の右寄せに並べています。パネルとは
  重なりません（`--lg-top-gap = --lg-gap + --lg-btn-strip` を上端だけに足している）。
  色は macOS 準拠（最小化=黄 / 最大化=緑 / 閉じる=赤、縁は少し濃い同色）、アイコンは
  普段は隠してホバー時だけ薄く出します。ボタン用に空ける幅 `--frame-right-space` も丸の
  大きさに合わせて詰めています。サイズ・色は `--lg-btn-*` で調整できます
  （丸＝`--lg-btn-size`、ホバー時のアイコン＝`--lg-btn-glyph-size` / `--lg-btn-glyph`）。
  アイコンは `<svg class="svg-icon">` とは限らない（class 無しの svg／擬似要素の背景画像・
  マスク）ため、大きさの指定はそれら全部に当たるようにまとめて書いています。
  なお既定はボタンを並べる箱（`.titlebar-button-container.mod-right`）に
  `--titlebar-background(-focused)` を敷きます。これは「枠なし＋フォーカス中」のときだけ
  詳細度が上がる（`(0,5,0)`）ため、`transparent !important` で打ち消しています
  （そのままだと丸の後ろだけ四角く色が残ります）。
- **ウィンドウのドラッグ領域**：枠なし（Windows / Linux の hidden frameless）では、移動が
  タブバーの空き部分頼みだとタブを多く開いたときに掴みにくくなります。そこで Electron の
  作法どおり、`.titlebar` 自体を「上端の帯」の高さ（`--lg-top-gap`）に縮めて
  `-webkit-app-region: drag` を与えています。ウィンドウ操作ボタンはその `.titlebar` の子
  なので、既定の `no-drag` がそのまま効きます（＝ドラッグ領域とボタンが重なってクリックを
  吸われる問題が起きず、帯のどこでも移動できてボタンも押せる）。左・下辺はドラッグにせず、
  リサイズを妨げません。`--lg-gap` を 0 にすると帯は消え、既定のタブバー移動だけになります。
- **コールアウト**：「種類ごとの色を薄く敷いた箱」だったのを、**色を残したガラスカード**に
  しています。ガラスの下地（`--lg-callout`）の上に、種類の色（`--callout-color`）を上澄み
  として薄く重ねる（`--lg-callout-tint`、既定 0.03、`0` で無色のガラス）ので、種類の
  見分けとガラス感が両立します。上澄みは `background-image` の `linear-gradient` ＋
  `color-mix(in srgb, var(--callout-color) calc(var(--lg-callout-tint) * 100%), transparent)`
  で作っています（新しい Obsidian では `--callout-color` が `#027aff` のような色そのものに
  なっていて、既定の `.callout` も同じ書き方をしているため。旧版の「2, 122, 255」形式では
  この宣言は無効になり、色は乗らずガラスの面だけが残ります）。枠は無彩色の輪郭
  （`--lg-rim-outline`）＋上辺のハイライト、影は `--lg-callout-shadow`。ぼかしはパネルより
  内側なので控えめ（`--lg-callout-backdrop` = `blur(12px) saturate(160%)`）。
  なお既定の `mix-blend-mode`（ダーク=lighten / ライト=darken）はライトの `darken` で
  明るい面が無効化されて塗りも色も消えるため、`normal` に固定しています（ダークは
  lighten と normal が同じ絵になるので見た目は変わりません）。
- **引用**：**ガラスのカード（`--lg-quote`。既定はコールアウトと同じ濃さ）＋左端の
  「背表紙」**（アクセント色の1本線。下に向かって薄く消えるので、硬い罫線に見えません）。
  背表紙は `::before` を**カードと同じ角丸**で敷いたうえに、横方向のグラデーションで
  左端 3px だけを塗り、縦方向のマスクで下を薄くして作っています。カード側を
  `overflow: hidden` で切る必要がないので、**引用の中に横長の表や大きな画像があっても
  欠けません**。入れ子の引用は面をやめて細い線だけにしています（カードが二重にならない
  ように）。編集中（ライブプレビュー）は行ごとの疑似要素で描かれるため角丸のカードには
  できませんが、`--blockquote-background-color` / `--blockquote-border-*` を設定して
  **面の色と線は読み取り表示と揃えて**います（角丸・上辺のハイライト・影は読み取り表示
  だけ）。

### 検証方法

スクリーンショットが使えない環境のため、`preview.html` / `preview-overlays.html` /
`preview-quotes.html`（引用の比較用）をブラウザで開き、`getComputedStyle` /
`getBoundingClientRect` の値で確認しています
（パネルの透過・ぼかし、タブのピル化、フォントが既定のままか、ドラッグ領域、
リサイズハンドルのヒットエリアなど）。
